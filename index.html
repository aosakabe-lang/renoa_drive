💡 まずはじめに：登場する主要ツールの役割

今回のデータ移行プロジェクトで登場する主要なクラウドサービスとツールの位置づけです。

Dropbox 移行元（現在）

現在利用中のクラウドストレージです。格納されているデータを新しい環境へ安全に引っ越しします。

Microsoft 365 総合環境

Officeアプリ（Excel, Word等）やSharePoint、Teamsを統合したMicrosoftのクラウドサービス基盤です。

SharePoint 移行先（チーム共有）

チーム全体の共有フォルダ（サイト）です。安全なアクセス制御のもと、同時編集やファイル管理が行えます。

OneDrive 個人領域 ＆ 同期

個人作業フォルダ機能に加え、SharePointのフォルダをPCのエクスプローラー（Finder）に同期表示するアプリです。

Migration Manager 公式移行ツール

DropboxからSharePointへ全自動転送を行うMicrosoft公式ツールです。バックグラウンドで安全にコピーを行います。

1. SharePointでの今後の運用可能性チェック（事前確認）

データ移行前に、日常業務がSharePoint上で支障なく運用可能か、以下の必須要件をチェック・検証します。

💾 容量・ストレージ上限チェック

Dropboxの現在のデータ総容量が、割り当てられたSharePointサイトの容量制限内に問題なく収まるか確認します。

🔒 権限設定・アクセス制御チェック

フォルダごとの閲覧・編集権限（アクセス範囲）がSharePoint上で正しく再現・運用できるか設計します。

💻 PC同期（OneDriveアプリ）動作チェック

これまで同様、エクスプローラー（Finder）上でファイル操作ができるよう、OneDrive同期機能の動作を確認します。

📘 使い方マニュアルの整備

移行後に迷わず操作できるよう、SharePointの基本操作（ブラウザ共有・同時編集・同期）ガイドを用意します。

2. Migration Manager（移行マネージャー）を選択する理由

1. Microsoft公式機能による高い信頼性

SharePoint/OneDriveの仕様（禁止文字、パス長制限、権限構造など）に完全準拠して安全に処理されます。

2. ローカル環境からの独立

クラウド間直接通信のため、PCの空き容量不足やネット切断、電源OFFの影響を受けずに転送が継続します。

3. 差分同期（Incremental Sync）

初回コピー後、変更・追加されたデータのみを追記できるため、通常業務を止めることなく平行稼働できます。

4. 完全な監査ログ出力

全ファイルの成功・失敗ログがCSVで可視化されるため、移行漏れのない確実なデータ検証が可能です。

4. 移行の流れ（行うこと全4ステップ）

01

Dropbox事前スキャン（チェックのみ実施）

データを変更せずMigration Managerでチェックのみ実行し、修正が必要なエラーの有無を確認します。

02

エラー箇所の修正（※該当時のみ）

事前スキャンでエラー（禁止文字等）が検出された場合のみ、一括転送前に対象ファイルの修正を行います。

03

初回一括コピー（全自動）

クラウド間で全体データを一括転送します（自動処理のためPCの待機や作業は不要です）。

04

SharePoint差分同期 ＆ 本番運用スタート

最終の変更差分を反映完了後、終わり次第SharePointでの本番運用を開始します。

5. 修正が必要かどうかのチェック（ガイドライン）

💡 修正作業に関する事前のご案内：
まず「事前スキャン（自動チェック）」を行います。エラー（修正が必要な項目）が検出された場合のみ、該当ファイルの修正作業が発生します。スキャン結果でエラーが0件の場合は、以下の修正作業は不要です。
1. ファイル名・フォルダ名の【使用禁止記号（9種類）】ルールを見る

SharePointでは以下の9種類の記号がファイル名やフォルダ名に含まれていると移行エラー（データ読み飛ばし・破損）の原因になります。

🚫 SharePointで絶対に使えない9つの記号 " * : < > ? / \ |
❌ エラーになるNG例（赤色部分がダメな記号）
  • ・売上データ:2026.xlsx (コロン不可)
  • ・企画案/最終版.pptx (スラッシュ不可)
  • ・Q&A?回答.docx (クエスチョン不可)
  • ・ 見積書.pdf (先頭・末尾のスペース不可)
⭕ 修正後の正しいOK例
  • ・売上データ-2026.xlsx (ハイフンに置換)
  • ・企画案_最終版.pptx (アンダースコアに置換)
  • ・Q_A_回答.docx (記号の削除・置換)
  • ・見積書.pdf (余分なスペースを削除)
2. フォルダ階層の長さ制限（文字数オーバー対策）

SharePointでは、「サイト名 ＋ フォルダ名 ＋ ファイル名」の合計長が218文字以上になると保存・アクセス不可のエラーになります。

❌ エラーになる階層（深くて長すぎる名前）

フォルダ/2026年度/第1四半期/営業部/関東エリア/新規開拓プロジェクト/提案資料/〇〇株式会社様向け最終提案書_ver2_修正版.pptx

⭕ 修正後のスッキリした構成（解決策）

フォルダ/2026_営業/新規PJ/〇〇様提案書_v2.pptx

※フォルダ名を短縮・階層を浅く移動することでエラーが解消します。
